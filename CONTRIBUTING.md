# Contributing

Thanks for helping improve TomiHub. Keep contributions clean, readable, and respectful of Roblox creators and players.

## Standards

- Keep Luau code readable and organized.
- Prefer clear names over joke/internal names for public files.
- Avoid changes that target third-party games without permission.
- Do not add bypasses, abuse features, credential collection, or stealth behavior.
- Document user-facing changes in `CHANGELOG.md`.

## Suggested Workflow

1. Create a small branch for one focused change.
2. Explain the goal in the commit message or pull request.
3. Keep formatting consistent with the surrounding files.
4. Test changes in an experience you own or are allowed to modify.

## Good First Improvements

- Move legacy scripts into a `src/` folder.
- Split repeated UI creation into helper functions.
- Add screenshots for the README.
- Create a proper Roblox Studio demo place.
