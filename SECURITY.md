# Security Policy

## Responsible Use

TomiHub is intended for Roblox projects you own, manage, or have explicit permission to test. Please do not use this repository to harm other creators' experiences, disrupt players, bypass platform protections, or violate Roblox terms.

## Reporting Issues

If you find a security or privacy issue in this repository, open a private report if GitHub makes that available, or contact the repository owner directly.

Please include:

- A short summary of the issue.
- Steps to reproduce it in an authorized test environment.
- Any affected files or commits.
- A suggested fix, if you have one.

## Out of Scope

Reports about exploiting third-party Roblox games, bypassing anti-cheat systems, or abusing platform APIs are out of scope for this project.
